## Принципы

- Телефон: одна колонка, CTA перед портретом, поля формы друг под другом, компактное меню.
- Планшет: услуги и процесс 2×2; FAQ и форма получают полную ширину.
- Ноутбук: компактные отступы и графика для низкого окна, полная строка навигации.
- Desktop: утвержденная композиция с ограничением контейнера 1400px на больших мониторах.
- Сохранены бирюзовая палитра, стекло, выбранные портреты и все шесть смысловых разделов.
- Стрелки в задачах не возвращены.
- У кнопок без иконки надпись центрируется по горизонтали и вертикали без оставленного места под удаленную иконку.

## Контрольные размеры

Телефоны: 320×568, 360×800, 375×667, 390×844, 393×852, 412×915, 430×932.
Планшеты: 768×1024, 800×1280, 820×1180, 834×1194, 1024×1366; горизонтально 1024×768, 1180×820, 1194×834.
Desktop: 1280×720, 1366×768, 1440×900, 1536×864, 1920×1080, 2560×1440.
Телефоны горизонтально: 667×375, 844×390, 932×430.

Отдельные изображения сделаны для трех ключевых компоновок всех шести разделов, а промежуточные размеры покрываются правилами, не отдельным PNG на каждую модель телефона. Концепты не являются подтверждением браузерных тестов на перечисленных размерах.

## Промпты и история

Все изображения созданы встроенным imagegen, без CLI/API fallback. Рядом с каждым изображением находится файл *-prompt.txt с точным запросом. В ревизиях запрос описывает локальную правку исходного макета. Старые изображения оставлены для истории; актуальные ссылки перечислены в таблице выше.

Кнопка ноутбучного первого экрана исправлена в laptop-01-v2.png по обратной связи пользователя. В мобильных задачах исправлена шапка, в услугах разделены текст и иллюстрация. Подбор окончательной пары шрифтов остается отдельным этапом.
