# Научные иллюстрации — 17 октября 2026

Шесть оригиналов созданы через Createya API моделью gpt-image2-t2i, разрешение 1K: четыре иллюстрации услуг, композиция из четырёх этапов процесса и иллюстрация контактов. Промпты: illustration-prompts-v2.json. Идентификаторы завершённых заданий сохранены в *-run.json; секреты не сохраняются.

Общий язык: научная CGI-графика, стекло, металл, оптические соединения и бирюзовый свет. Надписи страницы остаются HTML.

node scripts/prepare-generated-art.mjs убирает лишние внешние поля, переводит чёрный световой фон в альфа-канал и кодирует WebP в public/assets/generated. Процесс разделён на четыре фрагмента для размещения под соответствующими этапами. Исходные PNG не изменяются. Иллюстрации декоративные, неинтерактивные и загружаются перед появлением на экране.

scripts/createya-art.mjs принимает ключ через скрытый ввод, продолжает сохранённые задания и не пересоздаёт загруженные результаты. Повторная подготовка WebP не требует сети и ключа.
