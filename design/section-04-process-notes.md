# Экран 4: как проходит работа

Первый вариант: section-04-process-v1.png. Создан через встроенный imagegen для обсуждения.

Одна широкая стеклянная панель с четырьмя последовательными этапами: обсуждение задачи, согласование плана, разработка, проверка и запуск. Под каждым этапом указан его результат. Поддержка и развитие вынесены в отдельную оговорку без обещания включенного обслуживания.

Стеклянная линия связывает этапы, без стрелок и декоративной нумерации. Палитра и шапка наследуют утвержденный стиль. Портрета нет. Макет целиком помещается в горизонтальное окно.

Ниже 768px: этапы расположить вертикально в исходном порядке. Декоративную горизонтальную стеклянную линию убрать, каждый результат оставить рядом со своим описанием. Панель растет по содержимому, раздел не ограничивать высотой окна. Внешние отступы 20-24px, заголовок 32-36px, названия этапов 24px, основной текст 16-18px. Навигация компактная.

Движение при реализации: этапы появляются последовательно слева направо, на телефоне сверху вниз, только при первом появлении раздела. При reduced motion все содержимое видно сразу. Стеклянные объекты неподвижны во время чтения.

Проверка статического концепта: присутствуют четыре этапа, результаты и оговорка о поддержке; нет вымышленных сроков, цен и гарантий. Контраст необходимо измерить после реализации.
