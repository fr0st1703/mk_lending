# Экран 6: форма заявки

Основной концепт: section-06-contact-v1.png. Лист состояний: section-06-form-states-v1.png. Созданы через встроенный imagegen, первый вариант для обсуждения.

Форма содержит обязательные full_name, phone, message и отдельное обязательное privacy_consent без предварительной галочки. Поля ФИО и телефон рядом на компьютере, описание задачи на всю ширину. Подписи над полями, подсказки не заменяют подписи. Подложка под полями плотнее декоративного стекла для читаемости.

Пределы из брифа: ФИО 2-120 символов, описание 10-2000 символов. Визуальное решение предполагает обязательное описание задачи; окончательное продуктовое решение можно изменить. Телефон с кодом страны, ввод не ограничивать Россией.

## Состояния

- Обычное: пустые поля, согласие без галочки, кнопка «Отправить заявку».
- Фокус: отчетливая бирюзовая обводка активного поля, не передавать состояние только цветом; сохранить системную доступность фокуса.
- Ошибки: сообщение непосредственно под полем и связь через aria-describedby, aria-invalid. Для имени «Укажите ФИО, от 2 до 120 символов.», телефона «Введите номер с кодом страны.», описания «Опишите задачу, от 10 до 2000 символов.», согласия «Подтвердите согласие.» После попытки отправки перевести фокус на первое невалидное поле.
- Отправка: только после успешной проверки всех полей. Кнопка заблокирована, текст «Отправляем…», форма aria-busy. Значения сохраняются. Замаскированный телефон на листе состояний служит только для демонстрации, в рабочей форме введенный номер остается видимым.
- Успех: только после подтверждения сохранения заявки. Вместо формы «Заявка отправлена» и «Спасибо! Я свяжусь с вами, чтобы обсудить задачу.» Без обещания времени ответа. Объявить статус через live region, фокус на подтверждение.
- Сбой отправки: отдельное сообщение над кнопкой «Не удалось отправить заявку. Данные сохранены в форме. Попробуйте ещё раз.» Значения и согласие сохраняются. Вернуть кнопку в активное состояние, разрешить повторную попытку. Не показывать сообщение об успехе при неизвестном результате. Этот вариант описан в спецификации, отдельно не отрисован.

## Адаптация

Ниже 768px: заголовок и пояснение, затем форма в одну колонку. ФИО и телефон друг под другом. Декоративный стеклянный объект убрать либо значительно уменьшить, не откладывать доступ к форме. Высота раздела по содержимому. Внешние отступы 20-24px, подписи и ввод минимум 16px, интерактивные элементы минимум 44px, кнопка на всю ширину. Телефон type=tel, autocomplete=tel; ФИО autocomplete=name. При уменьшении прозрачности использовать плотные однотонные подложки. При reduced motion без автоматического движения.

## Материалы для завершения

Политика и формулировка согласия в макете обозначают место соответствующих материалов. Реальный документ, финальная формулировка и адрес ссылки пока не предоставлены. Контактные каналы не выдуманы, добавляются после предоставления владельцем. Футер включает только бренд и место ссылки на политику.

Контраст, фокус, поведение клавиатуры и адаптацию нужно проверить на реализованном интерфейсе. Сейчас готовы статические концепты, не работающая форма.
