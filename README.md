# Mihail Kozlov — лендинг автоматизации бизнеса

Лендинг и backend на Next.js App Router, React, TypeScript и Tailwind CSS. Заявки сохраняются в SQLite на сервере; собственная админ-панель доступна по `/admin`. Прототип сохранён отдельно и не используется приложением.

## Запуск

Требуется Node.js 24 или новее (используется встроенный `node:sqlite`).

```sh
npm ci
npm run admin:setup
npm run dev
```

Открыть http://127.0.0.1:3000. Для production: `npm run build`, затем `npm run start`.

Настройка создаёт `.env.local` и случайный пароль в `data/admin-access.txt`. Сохраните пароль в менеджере паролей и удалите файл. Эти файлы и база не попадают в Git. Повторный запуск настройки не перезаписывает существующий пароль. Если настройка уже выполнена, повторять её не нужно. Чтобы задать свой пароль на Windows, остановите сервер, выполните `npm run admin:password` и дважды введите новый пароль скрыто. Старые сессии завершатся. После изменения окружения перезапустите приложение.

## Источники дизайна

Приоритет: `instructions/PROJECT_BRIEF.md`, `instructions/DESIGN_PROMPT.md`, `design/README.md`, актуальные PNG, `design/responsive/RESPONSIVE_SPEC.md`, `design/MOTION_SPEC.md` и примечания к секциям.

Все шесть разделов реализованы HTML-компонентами. Научные иллюстрации услуг, процесса и контактов сгенерированы через Createya, оптимизированы в прозрачные WebP и загружаются при приближении к экрану компонентом `scientific-artwork.tsx`. Они не реагируют на курсор и не показывают браузерные элементы управления изображением. Оригиналы и промпты находятся в `design/generated`; `node scripts/prepare-generated-art.mjs` воспроизводит веб-версии. `npm run assets` воспроизводит WebP-портреты и резервный фон с точками и связями; скрипты требуют установленного `sharp`.

Типографика по выбору владельца: локальные Oswald Variable 600 для заголовков H1–H4 и Open Sans Variable для основного текста, меню, кнопок и форм. Кириллица и латиница, WOFF2, font-display: swap; браузер загружает только нужные подмножества. Внешних запросов к Google Fonts нет. Лицензии находятся в соответствующих пакетах Fontsource.

## Структура

- `src/app/page.tsx`: серверная структура, заголовки, тексты и JSON-LD.
- `src/app/globals.css`: токены, стекло, все адаптивы, настройки доступности.
- `src/components/network-background.tsx`: единая Canvas-сцена с двумя движущимися планами, локальное отталкивание мышью, постоянная анимация независимо от reduced motion, пауза скрытой вкладки и снижение сложности. Дальняя паутина размыта и рисуется в уменьшенном буфере; ближняя остаётся чёткой. Это уточнение владельца от 17 октября 2026 имеет приоритет над исходным правилом `MOTION_SPEC.md`; остальные UI-переходы продолжают учитывать reduced motion.
- `src/lib/network-motion.ts`: конфигурация `MOTION`, независимые плавные траектории X/Y/Z и перспективная проекция. Глубина меняет видимые размер, яркость и положение точек, без обновления React на каждом кадре.
- `src/components/header.tsx`: модальное меню на native dialog, Escape и управление фокусом.
- `src/components/faq.tsx`: пять вопросов, всегда ровно один открытый ответ, повторное нажатие не закрывает его. Высота списка резервирует самый длинный ответ с учётом фактической ширины и шрифтов; открытие вопросов не меняет размеры панели и страницы.
- `src/components/lead-form.tsx`, `src/lib/lead-schema.ts`: клиентская валидация, нормализация международного телефона, состояния, honeypot, блокировка повторной отправки.
- `src/app/api/leads/route.ts`: серверная проверка и сохранение заявок.
- `src/lib/server/`: база, сессии, ограничения запросов и проверка Origin.
- `src/app/admin/`, `src/app/api/admin/`: панель, статусы, удаление, Excel.
- `src/instrumentation.ts`: очистка просроченных данных при запуске и раз в час.

## Статус формы и политики

После `npm run admin:setup` локальный приём заявок включён. До настройки или при `LEADS_ENABLED=false` API отвечает 503. Данные хранятся в `data/landing.sqlite` (путь меняется через `DATABASE_PATH`). Успех возвращается после записи; повтор с тем же Idempotency-Key возвращает тот же ID, изменение содержимого под старым ключом даёт 409. Телефон не уникален: один клиент может оставить разные задачи.

Вход `/admin` использует пароль, scrypt-хеш, HttpOnly SameSite=Strict cookie и отзываемые серверные сессии на 8 часов. Панель содержит поиск (в том числе кириллица), статусы, страницы по 25 записей, безвозвратное удаление с подтверждением и экспорт всех неистёкших заявок в `.xlsx`. Телефоны и пользовательский текст в Excel записываются как строки, а не формулы. Уведомления не подключены.

`/privacy` и `/consent` содержат типовые тексты для Козлова Михаила Сергеевича (самозанятый), аудитория РФ и СНГ. Срок хранения — два календарных месяца. Очистка работает при запуске, раз в час и при операциях с заявками. Для остановленного приложения нужен внешний планировщик `npm run db:cleanup`. Excel-файлы и резервные копии удаляются оператором отдельно в тот же срок. Подробности размещения и юридической подготовки — [BACKEND_OPERATIONS.md](BACKEND_OPERATIONS.md).

Статистика считает загрузки главной страницы за 24 часа / 7 дней / 30 дней, с часовым округлением границ. Это не уникальные посетители; перезагрузка увеличивает счётчик. Cookies и персональные идентификаторы для аналитики не используются. Агрегаты хранятся 31 день. Панель показывает доступность базы, uptime и RSS текущего процесса Node; домен и SSL пока отмечены как не подключённые.

## SEO и домен

Включены семантические секции, один H1, русская локаль, title/description, Open Graph, изображение для ссылок, favicon и JSON-LD с реальными услугами и контактами. До определения домена страница имеет `noindex`, а sitemap пустой. HTML доступен для обхода, чтобы поисковики могли прочитать noindex. Порядок настройки домена и проверки индексации — [SEO_DEPLOY.md](SEO_DEPLOY.md).

После выбора домена дополнить существующий `.env.local` значениями из `.env.example`, не перезаписывая пароль. `APP_ORIGIN` — точный адрес сайта без завершающего слеша. `NEXT_PUBLIC_SITE_URL` включает индексацию после пересборки, поэтому задаётся при готовности к запуску. Внешний приём заявок требует HTTPS, `POLICY_READY=true` и заполненного `OPERATOR_ADDRESS`. Админ-панель и API закрыты от индексации.

## Проверки

```sh
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
node scripts/visual-qa.mjs
node scripts/performance-qa.mjs
```

Playwright проверяет 24 размера от 320 до 2560 px, обрезание текста, меню и фокус, FAQ, ошибки/сбой/отправку/подтверждённый успех формы, повторы и reduced motion. Axe проверяет WCAG A/AA на desktop и mobile. Эти автоматические проверки не заменяют тест на реальном iOS/Android и ручную оценку assistive technology.

Скриншоты находятся в `qa/screenshots`. Полный набор Playwright запускает отдельный production-процесс на порту 3100 с новой тестовой базой `data/test-e2e-*.sqlite` и тестовым паролем, не используя локальные рабочие заявки. Перед ним выполните сборку. Старые скрипты снимков и скорости используют уже работающий production-сервер на порту 3000.

Логотип шапки: исходник Photos/logo.png, подготовка node scripts/prepare-logo.mjs. Прозрачный WebP без пустых полей занимает около 6 KB; светлая версия для тёмной шапки задаётся CSS, исходник сохранён.
