# Локальный прототип Mihail Kozlov

Вопрос: сохраняет ли живая паутина глубину утверждённых макетов, оставаясь спокойной и мягко реагируя на курсор?

Запуск из корня проекта: `npm run prototype`. Открыть http://127.0.0.1:4173/prototype/ . Установка зависимостей не требуется, нужен Node.js.

Это отдельный, временный прототип, не production-реализация. Исходные материалы в `design/` и `Photos/` не изменены. По прямому требованию пользователя сохранён один дизайн; вместо разных композиций сравниваются настройки фона.

- `?variant=A`: тихий — цикл 90 с, дрейф 4 px, радиус 120 px, отталкивание 16 px.
- `?variant=B`: баланс (по умолчанию) — 70 с, 7 px, 140 px, 20 px.
- `?variant=C`: выразительный — 50 с, 10 px, 160 px, 24 px.
- Стрелки на панели / клавиши ← → переключают режим; настройки позволяют менять радиус и силу в пределах MOTION_SPEC.
- Кнопка паузы останавливает фон. Крестик убирает панель; кнопка «Фон» возвращает её. `&clean=1` скрывает панель сразу.
- В настройках можно выбрать успех или сбой демонстрационной формы. Никакой отправки, хранилища или аналитики нет. Политика — явно обозначенное место для будущего документа.

Одна Canvas 2D сцена, закреплённая за окном, сохраняет топологию и время при переходах между разделами. Размеры реакций заданы в CSS px. Экспоненциальное приближение без пружин и ускорений; дальний слой не реагирует. В скрытой вкладке RAF приостановлен, временной шаг ограничен. Reduced motion отключает оба эффекта; touch не включает отталкивание. Декоративные слои не перехватывают события. При длительной дорогой отрисовке уменьшается сложность, затем включается пауза.

Стеклянные иллюстрации услуг воссозданы CSS-геометрией и являются приближением растровых макетов. Использованы два утверждённых оригинальных портрета, Arial как временный шрифт (окончательная пара ещё не согласована).

Вердикт по интенсивности движения пока открыт — нужен просмотр владельцем. Репозитория Git и implementation issue в исходной папке нет, поэтому ветка/коммит/ссылка на issue не создавались. После выбора режима перенести подтверждённые параметры и решения в основную реализацию, архивировав этот прототип отдельно.

## Проверено 17 октября 2026

- HTTP 200; синтаксис трёх JS-файлов; в браузере нет предупреждений и ошибок JS.
- Размеры 320×568, 390×844, 834×1194, 1194×834, 1440×900, 2560×1440: шесть разделов, нет горизонтального переполнения текста/полей/кнопок.
- Визуально просмотрены первый экран desktop/mobile, услуги и подтверждение формы.
- Мобильное меню, Escape и возврат фокуса; FAQ закрывает предыдущий ответ; переключатель обновляет URL и значения настроек.
- Пустая форма показывает четыре ошибки и фокусирует первое поле. Валидные демонстрационные данные проходят состояние загрузки, затем успех либо выбранный сбой. Сбой сохраняет ввод и разблокирует повторную попытку. Окно политики работает.
- Встроенный браузер сообщает `prefers-reduced-motion: reduce`: проверено статичное состояние. Визуальная проверка анимации, реакции курсора и производительности в активном режиме пока НЕ выполнена. Реальные touch-устройства, зум 200/400% и остальные контрольные размеры пока не проверены.
